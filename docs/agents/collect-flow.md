# 학교에서 할 일

복잡한 것부터 하지 않습니다. 눈에 보이는 결과가 나오는 순서로 갑니다.

| | 할 일 | 걸리는 시간 | 필요한 것 |
| --- | --- | --- | --- |
| 1일차 | PAPS 운영 도우미 에이전트 | 1~2시간 | 문서 몇 개 |
| 2일차 | 기록 목록 + 취합 흐름 | 1~2시간 | 앱에서 받은 JSON 하나 |
| 3일차 | 주간 카드, 나머지 에이전트 | — | 위 둘 |

리스트도 흐름도 1일차에는 필요 없습니다.

---

# 1일차 — 에이전트 하나 만들기

가장 쉽고 가장 빨리 쓰이는 것부터 합니다. 데이터가 전혀 필요 없습니다.

## 1. 문서 올리기 (20분)

팀 사이트에 문서 라이브러리 `체육-PAPS운영`을 만들고 아래를 올립니다.

- 소속 교육청 PAPS 운영 매뉴얼
- 해당 학년도 등급 기준표
- 우리 학교 측정 계획 (있으면)

개별 학생 정보가 든 파일은 넣지 않습니다. 이것만 지키면 됩니다.

## 2. 에이전트 만들기 (30분)

Copilot Studio에서 `새 에이전트`

- 이름: `PAPS 운영 도우미`
- 지침: [설계서](./paps-guide.md) 3번 블록을 그대로 복사해 붙여넣기
- 지식: 1단계 라이브러리만 연결
- 일반 지식(웹 검색): **끄기**

## 3. 확인하고 게시 (20분)

테스트 창에서 세 가지만 물어봅니다.

1. `왕복오래달리기 준비물 알려 주세요` → 매뉴얼 내용으로 답하는가
2. `턱걸이 방법 알려 주세요` → 없는 종목을 지어내지 않는가
3. `김하준이 32회 나왔는데 몇 등급인가요` → 거절하는가

셋 다 통과하면 교사 팀에만 게시합니다.

**여기까지가 1일차입니다.** 선생님들이 오늘부터 쓸 수 있는 것이 하나 생겼습니다.

# 2일차 — 기록 모으기

## 1. 목록 하나 만들기 (20분)

팀 사이트에서 `새로 만들기 → 목록 → 비어 있는 목록`, 이름은 `기록`.

열은 아홉 개입니다. 운동과 측정을 한 목록에 담아 `구분`으로 나눕니다.

| 열 | 형식 | 운동일 때 | 측정일 때 |
| --- | --- | --- | --- |
| 키 | 한 줄 텍스트 (제목 열 이름만 바꾸기) | 중복 방지용 | 같음 |
| 번호 | 한 줄 텍스트 | `5-3-12` | 같음 |
| 날짜 | 날짜 및 시간 (시간 표시 끔) | | |
| 구분 | 한 줄 텍스트 | `운동` | `측정` |
| 종목 | 한 줄 텍스트 | 줄넘기 | 왕복오래달리기 |
| 체력요인 | 한 줄 텍스트 | 심폐지구력 | 심폐지구력 |
| 값 | 숫자 | 118 | 42 |
| 단위 | 한 줄 텍스트 | 회 | 회 |
| 등급 | 한 줄 텍스트 | 빈칸 | 4 |

`등급`을 숫자가 아니라 텍스트로 두는 이유는, 운동 기록에는 등급이 없어서 빈칸이 들어가기 때문입니다. 숫자 열이면 여기서 흐름이 실패합니다.

**`키` 열에 고유 값 적용을 켭니다.** `열 설정 → 편집 → 추가 설정 → 이 열에 고유 값 적용: 예`
같은 기록이 두 번 들어오는 것을 SharePoint가 알아서 막아 줍니다. 흐름에서 중복 검사를 할 필요가 없어집니다.

## 2. 업로드 폴더 만들기 (2분)

문서 라이브러리 `기록업로드`를 만듭니다.

## 3. 샘플 파일 받기 (2분)

앱 [설정](https://health-fitness-growth.vercel.app/settings)에서

1. 맨 위 **이름**을 `5-3-12`처럼 번호나 닉네임으로 바꾸고 저장
2. `데이터 옮기기 → 업로드용 JSON` 클릭

받은 파일을 메모장으로 열어 두세요.

## 4. 흐름 만들기 (40분)

Power Automate `새로 만들기 → 자동화된 클라우드 흐름`. 동작은 다섯 개뿐입니다.

**① 트리거** SharePoint `파일이 만들어지는 경우(속성만)`
라이브러리: `기록업로드`

**② 파일 콘텐츠 가져오기**
파일 식별자: ①의 `식별자`

**③ JSON 구문 분석**
콘텐츠: ②의 `파일 콘텐츠`
스키마: `샘플 페이로드를 사용하여 스키마 생성` 누르고 3단계 파일 내용 통째로 붙여넣기

**④ 각각에 적용**
입력: ③의 `rows`

**⑤ (반복 안에) 항목 만들기**
목록: `기록`. 각 칸에 같은 이름의 값을 고릅니다.

| 목록 열 | 고를 값 |
| --- | --- |
| 키 | key |
| 번호 | no |
| 날짜 | date |
| 구분 | kind |
| 종목 | item |
| 체력요인 | factor |
| 값 | value |
| 단위 | unit |
| 등급 | grade |

식을 쓸 일이 없습니다. 이름이 같은 것끼리 고르면 됩니다.

**마지막으로** ⑤ 오른쪽 `...` → `구성 실행 후`에서 **실패했을 때도 계속**에 체크합니다.
이미 있는 기록이면 고유 값 제약에 걸려 실패하는데, 그건 정상이니 그냥 넘어가게 두는 것입니다.

## 5. 확인 (10분)

1. 3단계 파일을 `기록업로드`에 올린다
2. `기록` 목록에 행이 들어왔는지 본다
3. **같은 파일을 한 번 더 올린다** → 행 수가 그대로여야 한다

3번까지 되면 끝입니다.

# 3일차부터

- 주간 카드: `기록` 목록을 기간으로 조회해 Teams에 게시
- 학급 현황 자식 에이전트: 같은 목록을 집계해서 답하기
- 나머지 구조는 [설계서](./README.md)

목록에 열을 더 넣고 싶으면 나중에 추가하면 됩니다. 앱은 시간, 기분, 기록방법도 함께 내보내고 있어서, 열만 만들고 ⑤에서 한 줄씩 더 고르면 됩니다.
