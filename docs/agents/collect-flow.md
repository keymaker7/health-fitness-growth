# 기록 취합 흐름(P1) 만들기

학교에서 처음부터 따라 할 수 있는 절차입니다. 여기까지 되면 나머지 흐름은 전부 같은 리스트를 읽는 반복 작업입니다.

준비물: 팀 사이트 편집 권한, Power Automate 접근 권한, 앱에서 받은 업로드용 JSON 파일 하나

---

## 1. 리스트 만들기

팀 사이트에서 `새로 만들기 → 목록 → 비어 있는 목록`으로 세 개를 만듭니다.
기본 `제목` 열을 그대로 쓰되 이름만 바꿉니다.

`새로 만들기 → 문서 라이브러리`로 만들고, 안에 `처리완료` 폴더를 하나 만들어 둡니다.

---

## 2. 샘플 파일 준비

앱 [설정](https://health-fitness-growth.vercel.app/settings)에서

1. 맨 위 **이름** 칸을 `5-3-12`처럼 번호나 닉네임으로 바꾸고 저장
2. `데이터 옮기기 → 업로드용 JSON` 클릭

받은 파일을 메모장으로 열어 두세요. 4단계에서 스키마 생성에 붙여 넣습니다.

---

## 3. 흐름 만들기 — 트리거

Power Automate에서 `새로 만들기 → 자동화된 클라우드 흐름`

- 트리거: SharePoint **파일이 만들어지는 경우(속성만)**
- 사이트 주소: 팀 사이트
- 라이브러리 이름: `기록업로드`
- 폴더: 비워 둠

> `처리완료` 폴더로 파일을 옮기면 트리거가 다시 걸릴 수 있습니다. 6단계에서 막습니다.

---

## 4. 파일 읽고 해석하기

**① 파일 콘텐츠 가져오기** (SharePoint)
- 파일 식별자: 트리거의 `식별자`

**② JSON 구문 분석** (Parse JSON)
- 콘텐츠: ①의 `파일 콘텐츠`
- 스키마: `샘플 페이로드를 사용하여 스키마 생성`을 누르고 2단계 파일 내용을 통째로 붙여 넣기

생성된 스키마에서 `mood`처럼 비어 있을 수 있는 값은 `"type": "string"`을 `"type": ["string", "null"]`로 고쳐 둡니다. 안 고치면 값이 빈 날 흐름이 실패합니다.

**③ 변수 초기화** — 이름 `학생번호`, 형식 문자열, 값 `body('JSON_구문_분석')?['student']?['no']`

---

## 5. 운동기록 넣기

**④ 각각에 적용** — 입력: ②의 `workouts`

설정에서 **동시성 제어를 켜고 1로** 낮춥니다. 기본값이면 같은 키가 동시에 두 번 들어갑니다.

반복 안에 세 개를 넣습니다.

**⑤ 항목 가져오기** (SharePoint)
- 목록: `운동기록`
- 필터 쿼리: `Title eq '@{items('각각에_적용')?['key']}'`
- 상위 개수: 1

**⑥ 조건** — `length(body('항목_가져오기')?['value'])` 가 `0` 과 같음

**⑦ 예인 경우 → 항목 만들기** (SharePoint)
- 목록: `운동기록`
- 키: `items('각각에_적용')?['key']`
- 번호: 변수 `학생번호`
- 날짜: `items('각각에_적용')?['date']`
- 시각 / 종목 / 체력요인: 각각 `time` `exercise` `factor`
- 횟수 / 시간분 / 정확도: `count` `minutes` `accuracy`
- 운동후기분 / 기록방법: `mood` `method`

아니요인 경우는 비워 둡니다. 이미 있는 기록이라 건너뛰는 것이 맞습니다.

---

## 6. PAPS 넣고 파일 정리

**⑧ 각각에 적용** — 입력: ②의 `paps`. 동시성 1.
⑤~⑦과 같은 방식으로 `PAPS측정` 목록에 넣습니다. 열 이름만 다릅니다.

**⑨ 파일 이동** (SharePoint)
- 현재 파일: 트리거의 `식별자`
- 대상 폴더: `기록업로드/처리완료`
- 이미 있으면: 이름 바꾸기

**⑩ 흐름 실패 시 알림**
`구성 실행 후` 설정에서 앞 동작이 실패했을 때만 실행되는 Teams 메시지를 하나 붙입니다. 조용히 실패하면 데이터가 비는 걸 몇 주 뒤에 알게 됩니다.

---

## 7. 검증

1. 2단계 파일을 `기록업로드`에 올린다
2. 흐름 실행 기록에서 성공 확인
3. `운동기록` 목록에 행이 들어왔는지 확인
4. **같은 파일을 한 번 더 올린다** → 행 수가 늘지 않아야 함
5. 파일이 `처리완료`로 옮겨졌는지 확인

4번이 핵심입니다. 여기가 되면 선생님이 실수로 두 번 올려도 데이터가 망가지지 않습니다.
