# 하루에 끝내기

## 09:00 — 준비 점검 (30분)

**먼저 5분만 확인하세요.** 여기서 막히면 하루가 통째로 날아갑니다.

- [ ] Copilot Studio에 들어가 새 에이전트를 만들 수 있는가
- [ ] Power Automate에서 SharePoint 커넥터가 붙는가
- [ ] 팀 사이트에 문서 라이브러리를 만들 권한이 있는가

문서 라이브러리 `체육-PAPS운영`을 만들고 **지금 바로** 올립니다. SharePoint 색인에 시간이 걸려서, 늦게 올리면 오후에 에이전트가 문서를 못 찾습니다.

- 소속 교육청 PAPS 운영 매뉴얼
- 해당 학년도 등급 기준표
- 우리 학교 측정 계획 (있으면)
- [운동처방 규칙](./prescription-rules.md) — 이 파일을 PDF나 Word로 변환해서 함께 올립니다
- [수업용 지식](./knowledge-class.md) — 측정 웹 주소와 성취기준. 없으면 본시 질문에 대답이 비웁니다
- [6학년 수업지도안](../lesson/grade6.md) — 성취기준과 차시. 에이전트가 수업 맥락을 말할 때 씁니다.

개별 학생 정보가 든 파일은 넣지 않습니다.

앱 [설정](https://health-fitness-growth.vercel.app/settings)에서 이름을 `5-3-12`처럼 바꾸고 `업로드용 JSON`을 받아 둡니다.

## 09:30 — 목록 만들기 (30분)

팀 사이트 `새로 만들기 → 목록 → 비어 있는 목록`, 이름 `기록`.

| 열 | 형식 |
| --- | --- |
| 키 | 한 줄 텍스트 (제목 열 이름만 바꾸기) |
| 번호 | 한 줄 텍스트 |
| 날짜 | 날짜 및 시간 (시간 표시 끔) |
| 구분 | 한 줄 텍스트 |
| 종목 | 한 줄 텍스트 |
| 체력요인 | 한 줄 텍스트 |
| 값 | 숫자 |
| 단위 | 한 줄 텍스트 |
| 등급 | 한 줄 텍스트 |

`등급`은 반드시 텍스트입니다. 운동 기록에는 등급이 없어 빈칸이 들어갑니다.

**`키` 열에 고유 값 적용을 켭니다.** `열 설정 → 편집 → 추가 설정 → 이 열에 고유 값 적용: 예`

문서 라이브러리 `기록업로드`도 하나 만듭니다.

## 10:00 — 취합 흐름 P1 (1시간)

Power Automate `새로 만들기 → 자동화된 클라우드 흐름`. 동작 다섯 개입니다.

**① 트리거** SharePoint `파일이 만들어지는 경우(속성만)` · 라이브러리 `기록업로드`

**② 파일 콘텐츠 가져오기** · 파일 식별자: ①의 `식별자`

**③ JSON 구문 분석** · 콘텐츠: ②의 `파일 콘텐츠`
스키마는 `샘플 페이로드를 사용하여 스키마 생성`을 누르고 아침에 받은 파일 내용을 붙여넣습니다.

**④ 각각에 적용** · 입력: ③의 `rows`

**⑤ 항목 만들기** (반복 안) · 목록 `기록`

| 목록 열 | 고를 값 |
| --- | --- |
| 키 | key |
| 번호 | no |
| 날짜 | date |
| 구분 | kind |
| 종목 | item |
| 체력요인 | factor |
| 값 | value |
| 단위 | unit |
| 등급 | grade |

⑤의 `...` → `구성 실행 후` → **실패했을 때도 계속**에 체크합니다. 이미 있는 기록은 고유 값 제약에 걸려 실패하는데, 그게 정상입니다.

**확인** 파일을 올려 행이 들어오는지 보고, 같은 파일을 한 번 더 올려 행 수가 그대로인지 봅니다.

## 11:00 — 부모와 첫 자식 (1시간)

### 부모 에이전트

Copilot Studio `새 에이전트` · 이름 `체육 운영 도우미`

지침에 붙여넣기

```
당신은 초등학교 체육 담당 교사를 돕는 안내 담당입니다.
직접 답하지 말고, 질문의 성격에 따라 알맞은 담당에게 넘깁니다.

- PAPS 종목의 측정 방법, 준비물, 안전, 파울 규정 → 측정 안내
- 운동처방의 숫자와 근거, 왜 이런 계획이 나왔는지 → 처방 해설
- 우리 반이 얼마나 하고 있는지, 참여율, 요인별 분포 → 학급 현황
- 건강체력교실 계획서와 보고서 → 건강체력교실 운영

어디에도 해당하지 않으면 무엇을 알고 싶은지 되묻습니다.
개별 학생의 이름과 측정값은 어떤 경우에도 대화에 남기지 않습니다.
사용자가 입력하면 지우도록 안내하고 학급 단위 질문으로 바꿔 달라고 요청합니다.
교사에게 말하듯 간결한 존댓말을 씁니다.
```

### 자식 — 측정 안내

`에이전트 → 자식 에이전트 추가` · 이름 `측정 안내`

- 설명(부모가 라우팅에 씁니다): `PAPS 13개 종목의 측정 방법, 준비물, 안전 수칙, 파울 규정을 매뉴얼 근거로 안내합니다.`
- 지식: `체육-PAPS운영` 라이브러리
- 일반 지식(웹 검색): **끄기**
- 지침: [PAPS 운영 도우미 설계서](./paps-guide.md)의 3번 블록을 그대로 붙여넣기

### 확인

1. `왕복오래달리기 준비물 알려 주세요` → 매뉴얼 내용으로 답하는가
2. `턱걸이 방법 알려 주세요` → 없는 종목을 지어내지 않는가
3. `김하준이 32회 나왔는데 몇 등급인가요` → 거절하는가

## 13:00 — 학급 현황 (1시간)

### 에이전트 플로우 F1

Copilot Studio 안에서 `도구 → 새 도구 → 에이전트 플로우`, 이름 `학급요약조회`

- 입력: `학년`(숫자), `반`(텍스트), `기간일수`(숫자)
- 동작 1: SharePoint `항목 가져오기` · 목록 `기록` · 필터 쿼리 `구분 eq '운동'`
- 동작 2: `작성` — 항목 수, 학생 번호의 고유 개수, 체력요인별 개수
- 출력: 위 세 값

**개별 행은 절대 반환하지 않습니다.** 집계값만 내보내면 프롬프트로 유도해도 샐 것이 없습니다.

### 자식 — 학급 현황

- 설명: `우리 반의 참여율과 체력요인별 분포를 알려 줍니다. 개별 학생 조회는 하지 않습니다.`
- 도구: F1 연결
- 지침

```
학급 단위 집계만 답합니다.
숫자는 반드시 학급요약조회 도구가 돌려준 값을 그대로 씁니다. 스스로 계산하거나 추정하지 않습니다.
개별 학생을 묻는 질문은 거절하고, 학급 단위로 다시 물어 달라고 안내합니다.
답변은 다섯 줄을 넘기지 않습니다.
```

## 14:00 — 처방 해설 (1시간)

`자식 에이전트 추가` · 이름 `처방 해설`

- 설명: `앱이 만든 4주 운동처방의 숫자와 근거를 설명합니다. 학부모 상담과 관리자 질의에 씁니다.`
- 지식: `체육-PAPS운영` 라이브러리 (아침에 올린 운동처방 규칙 문서가 여기 있습니다)
- 일반 지식: **끄기**
- 지침

```
당신은 건강체력 성장일지 앱이 만든 운동처방을 설명하는 담당입니다.

원칙
- 숫자는 연결된 운동처방 규칙 문서에 있는 값만 씁니다. 문서에 없으면 "규칙 문서에서 확인되지 않습니다"라고 답합니다.
- 답변에는 어떤 지침에서 온 값인지 함께 적습니다. 예: (WHO 2020 / ACSM 유연성 지침)
- 왜 그렇게 정했는지를 함께 설명합니다. 특히 최고 기록이 아니라 최근 3회 평균을 기준으로 삼는 이유,
  주간 총량을 110%로 제한하는 이유를 자주 묻습니다.

하지 않는 것
- 개별 학생의 처방 내용을 만들거나 판정하지 않습니다. 처방은 앱이 만듭니다.
- 의학적 진단, 체중 감량, 식단 조언을 하지 않습니다.
- 학생 이름이나 측정값이 입력되면 지우도록 안내합니다.

말투
- 학부모에게 그대로 읽어 줄 수 있을 만큼 쉬운 문장으로 씁니다.
```

확인 질문: `왜 최고 기록이 아니라 평균으로 목표를 잡나요`, `유연성은 왜 횟수가 아니라 초로 처방하나요`

## 15:00 — 연결 에이전트 (30분)

`건강체력교실 운영`을 **별도 에이전트로** 새로 만들어 게시한 뒤, 부모의 `에이전트` 화면에서 연결합니다.

- 지식: 교육청 기본 계획, 학교 운영 계획, 서식
- 지침

```
당신은 PAPS 저체력(4~5등급) 학생을 위한 건강체력교실 운영을 돕는 담당입니다.
계획서, 주차별 운영안, 결과 보고서의 초안을 만듭니다.

- 연결된 교육청 문서와 학교 계획에 있는 형식을 따릅니다.
- 초안임을 밝히고, 학교 사정에 맞게 고쳐 쓰도록 안내합니다.
- 참여 학생의 이름이나 측정값은 넣지 않습니다. 인원수만 씁니다.
```

부모에서 연결할 때 설명을 적습니다: `건강체력교실 계획서와 보고서 초안을 만듭니다.`

시간이 없으면 이 단계를 버려도 됩니다.
