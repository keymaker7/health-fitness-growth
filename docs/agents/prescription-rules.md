# 운동처방 규칙

> 이 문서를 그대로 SharePoint 문서 라이브러리에 올려 **처방 해설** 에이전트의 지식으로 씁니다.
> 앱이 실제로 쓰는 규칙과 같습니다. 앱을 고치면 이 문서도 함께 고칩니다. (원본: `src/lib/prescription.ts`)

## 무엇을 하는 처방인가

건강체력 성장일지 앱은 학생이 남긴 최근 4주 운동 기록을 읽어 4주 계획을 만듭니다.
교사가 등급을 입력해 주는 방식이 아니라, 학생이 실제로 한 운동이 다음 계획을 정합니다.

읽는 값은 다섯 가지입니다.

- 운동 횟수와 시간
- 종목별 기록 수치 (줄넘기 몇 회 등)
- 자세 정확도
- 운동 뒤 기분
- 체력 요인별 최근 운동량

이 활동은 2022 개정 체육과 성취기준 [6체01-02](측정하고 자기 수준에 맞는 운동을 시도), [6체01-05](체력 운동을 규칙적으로 수행)와 연결됩니다. 한 번 재서 등급을 내는 것이 목적이 아닙니다.

## 어떤 종목이 처방되는가

체력 요인마다 **필요도**를 계산해 가장 높은 두 요인을 고릅니다.

```
필요도 = (6 − 별 개수) × 10 − 최근 4주 운동 분(최대 60) × 0.6 − 최근 4주 횟수 × 1.5
```

별 개수는 PAPS 등급을 뒤집은 값입니다. 1등급이면 별 5개, 5등급이면 별 1개입니다.
즉 **측정 등급이 낮을수록, 최근에 덜 했을수록** 그 요인이 먼저 처방됩니다.

종목은 세 개에서 네 개입니다. 1순위 요인에서 두 종목, 2순위 요인에서 한 종목을 뽑고,
이미 잘하고 있는 요인이 있으면 거기서 한 종목을 `유지`로 남깁니다.
약점만 다루면 학생이 열심히 한 종목이 화면에서 사라져 동기가 꺾이기 때문입니다.

## 요인별 빈도와 시간

| 체력 요인 | 주당 횟수 | 1회 시간 | 한 번에 얼마나 | 비연속일 |
| --- | --- | --- | --- | --- |
| 심폐지구력 | 3~5회 | 5~15분 | 숨이 조금 차고 말은 할 수 있는 정도 | |
| 근력 | 2~3회 | 5~20분 | 한 세트 8~15회, 1~2세트 | 필요 |
| 근지구력 | 2~3회 | 5~15분 | 한 세트 12~20회, 1~2세트 | 필요 |
| 유연성 | 3~7회 | 5~10분 | 한 부위 10~30초씩 2~4번, 합쳐서 60초 | |
| 신체조성 | 3~5회 | 10~20분 | 즐겁게 오래 움직이는 활동 | |
| 순발력 | 2~3회 | 5~10분 | 짧고 가볍게, 착지를 부드럽게 | 필요 |
| 민첩성 | 2~3회 | 5~10분 | 짧게 여러 번, 사이에 충분히 쉬기 | |
| 평형성 | 3~5회 | 3~10분 | 천천히, 흔들려도 다시 서기 | |
| 협응성 | 3~5회 | 3~10분 | 정확한 동작을 먼저 | |
| 반응시간 | 2~3회 | 3~10분 | 놀이처럼 짧게 | |

비연속일이 표시된 요인은 이틀 연속 하지 않고 하루씩 쉽니다.

## 목표 횟수를 정하는 법

**최고 기록이 아니라 최근 3회 평균**을 기준으로 삼습니다.
최고 기록은 컨디션이 좋았던 하루일 뿐이어서, 그것을 기준으로 잡으면 매번 자기 최고치를 갱신하라는 요구가 됩니다.

목표를 올리는 조건은 아동 저항운동 지침의 이중 점증을 따릅니다.

| 상황 | 다음 목표 |
| --- | --- |
| 최근 3회 중 2회 이상 평균을 해냄 | 평균의 **105%** (강도가 올림이면 110%) |
| 아직 그만큼 못 해냄 | 평균 그대로 유지 |
| 자세 정확도 90% 미만 | 평균 그대로 유지. 자세 교정을 먼저 안내 |
| 강도가 낮춤 | 평균의 95% |

유연성은 횟수로 처방하지 않고 유지 시간으로 처방합니다.

## 강도를 정하는 법

| 조건 | 강도 | 처방에 반영되는 것 |
| --- | --- | --- |
| 운동 뒤 `지침·걱정`이 절반을 넘음 | 낮춤 | 1회 시간 −2분, 빈도는 최소치, 목표 −5% |
| 최근 4주 주 2회 미만 | 올림 | 1회 시간 +2분, 빈도는 상한까지 |
| 주 4회 이상이고 지친 기록이 25% 미만 | 올림 | 목표 상승폭 10% |
| 그 밖 | 유지 | 종목 기본값 |

## 안전 장치

**주간 총량 상한.** 계획 전체의 주당 분이 최근 실제 운동량의 110%를 넘으면 빈도와 시간을 자동으로 줄입니다.
갑자기 운동량을 늘려 다치는 것을 막는 점증 10% 원칙입니다.

다만 지침의 최소 권고량이 그 상한보다 큰 경우가 있습니다. 거의 움직이지 않던 학생이 그렇습니다.
이때는 계획을 깎아 권고 미달로 만들지 않고 **"첫 주는 절반만 하고 2주차부터 채워요"** 라고 안내합니다.

**재계산 주기.** 앱 처방은 4주마다 다시 계산합니다. PAPS 재측정은 학교 일정(보통 4·7·10월)을 따릅니다.

**기록이 적을 때.** 최근 4주 기록이 3개 미만이면 임시 계획이라고 화면에 표시합니다.

## 숫자의 근거

| 지침 | 반영한 내용 |
| --- | --- |
| WHO 2020 신체활동 지침 / 질병관리청 국가건강정보포털 | 5~17세는 하루 평균 60분 이상 중강도 이상 활동, 주 3일 이상 고강도 유산소와 근력·뼈 강화 |
| 미국소아과학회(AAP), 캐나다운동생리학회(CSEP) | 아동 저항운동은 주 2~3회 비연속일, 8~15회 1~2세트로 시작, 바른 자세로 상한을 채우면 5~10%씩 점증 |
| ACSM 유연성 지침 | 주 2~3일 이상, 정적 스트레칭 10~30초 유지, 2~4회 반복해 부위당 총 60초 |
| 점증 10% 원칙 | 주간 총량은 최근 실제 운동량의 110%를 넘지 않음 |
| 교육부 PAPS 운영 매뉴얼 | 평가 결과로 종목별 목표와 신체활동 목표횟수를 처방으로 등록 |
| 건강체력교실 운영 실태 연구 | 학교에서 가장 흔한 형태가 60분 미만·2개 종목 병행 |

## 이 처방이 하지 않는 것

- 의학적 진단이나 소견을 내지 않습니다.
- 체중 감량, 식단, 약물에 대해 조언하지 않습니다.
- 다른 학생과 비교하지 않습니다.
- 통증이 있으면 즉시 중단하고 교사에게 알리도록 안내합니다.
