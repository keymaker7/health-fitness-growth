# Microsoft 에이전트 · 워크플로 설계

건강체력 성장일지에 붙이는 Microsoft Copilot Studio 에이전트와 Power Automate 흐름의 설계서를 모읍니다.
Microsoft 제품만 사용합니다.

## 전제

- 앱의 학생 기록은 **브라우저 IndexedDB**에만 저장됩니다. 에이전트와 흐름은 앱 데이터베이스를 직접 읽지 못합니다.
- 에이전트에 넣는 학급 데이터는 **익명 집계값**만 사용합니다. 개별 학생 측정값은 지식 원본에 올리지 않습니다.
- 모든 에이전트는 학교 Microsoft Entra ID 테넌트 안에서만 게시하고, 공유 파일에는 Purview 민감도 레이블을 겁니다.
