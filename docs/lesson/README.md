# 수업 산출물

해커톤 필수 산출물인 **수업지도안**과 에이전트 시연 자료입니다.

| 파일 | 용도 |
| --- | --- |
| [6학년 수업지도안](./grade6.md) | 성취기준·차시·본시 과정·평가·시연 대본 |
| [에이전트 시연 질문](./agent-demo.md) | 심사 자리에서 그대로 입력할 질문과 기대 답 |

SharePoint `체육-PAPS운영` 라이브러리에 수업지도안과 [운동처방 규칙](../agents/prescription-rules.md)을 함께 올리면, 에이전트가 “이 수업이 왜 이 성취기준인지”도 같은 근거로 말합니다.
