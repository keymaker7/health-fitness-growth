# 진행 순서

학생이 실제로 한 **운동 기록이 쌓이면 처방이 그에 맞게 달라지는 것**이 이 앱의 중심입니다.
교사가 등급을 매겨 주는 방식이 아니라, 아이가 남긴 값이 다음 계획을 정합니다.

## 데이터가 처방으로 바뀌는 길

```
학생이 운동 / 측정 도구 사용
        ↓  값을 기록에 담기
최근 4주 기록 (횟수, 시간, 정확도, 운동 뒤 감정, 연속일)
        ↓  요인별 운동량 + 기준선 등급으로 필요도 계산
가장 부족한 힘 2개 선택 → 종목·주당 횟수·1회 시간·목표치·강도 결정
        ↓
4주 운동처방 → 실행 → 새 기록 → 4주 뒤 다시 계산
```

## 처방 수치의 근거

숫자는 임의로 정하지 않고 아래 지침에서 가져왔습니다. 화면에도 같은 출처를 적어 둡니다.

| 지침 | 반영한 내용 |
| --- | --- |
| WHO 2020 신체활동 지침 / 질병관리청 국가건강정보포털 | 5~17세는 하루 평균 60분 이상 중강도 이상 활동, 주 3일 이상 고강도 유산소와 근력·뼈 강화. → 심폐지구력 처방은 주 3~5회 |
| 미국소아과학회(AAP), 캐나다운동생리학회(CSEP) 아동 저항운동 지침 | 주 2~3회 **비연속일**, 8~15회 1~2세트로 시작, 바른 자세로 상한을 채우면 5~10%씩 점증(이중 점증). → 근력·근지구력 처방과 목표 상승 규칙 |
| ACSM 유연성 지침 | 주 2~3일 이상, 정적 스트레칭 10~30초 유지, 2~4회 반복해 부위당 총 60초. → 유연성은 횟수가 아니라 유지 시간으로 처방 |
| 점증 10% 원칙 | 주간 총량은 최근 실제 운동량의 110%를 넘지 않게 자동으로 줄임 |
| 교육부 PAPS 운영 매뉴얼 | 평가 결과로 종목별 목표와 신체활동 목표횟수를 처방으로 등록하는 구조를 따름 |
| 건강체력교실 운영 실태 연구 | 실제 학교에서 가장 흔한 형태가 60분 미만·2개 종목 병행. → 처방 종목을 3개로 제한 |

지침의 최소 권고량이 점증 상한보다 클 때가 있습니다. 이때는 계획을 깎지 않고
"첫 주는 절반만 하고 2주차부터 채워요"라고 알려 줍니다.

`npm run check:prescription`으로 다섯 가지 학생 유형(기록 없음 / 꾸준함 / 지침 / 자세 부정확 / 매우 활발)의
처방 결과를 한 번에 확인할 수 있습니다.

## 처방이 값을 읽는 방식

| 학생이 남긴 값 | 처방에서 달라지는 것 |
| --- | --- |
| 최근 4주 운동 횟수 (주 2회 미만) | 강도 `올림` — 종목당 시간 +2분, 요인별 상한까지 빈도 증가 |
| 주 4회 이상 + 지친 기록 적음 | 강도 `올림` — 목표 상승폭 10% |
| 운동 뒤 `지침·걱정`이 절반 넘음 | 강도 `낮춤` — 시간 −2분, 빈도 최소치, 목표 −5% |
| 종목별 최근 3회 평균 | 다음 목표치의 기준 (최고 기록이 아니라 재현 가능한 수준) |
| 최근 3회 중 2회 이상 평균 달성 | 이중 점증 조건 충족 → 목표 +5%(강도 올림이면 +10%) |
| 자세 정확도 90% 미만 | 목표를 올리지 않고 자세 교정을 먼저 안내 |
| 요인별 최근 4주 운동 분 | 적게 한 요인일수록 필요도가 올라가 처방 종목에 뽑힘 |
| 이미 잘하고 있는 요인 | 한 종목을 `유지` 처방으로 남겨 열심히 한 종목이 사라지지 않게 함 |
| PAPS 등급 (기준선) | 별이 적은 요인일수록 필요도 가산 |

구현: `src/lib/prescription.ts`, 화면 `/prescription`.

## 완료

### 운동처방 엔진과 화면
기록에서 4주 계획을 만듭니다. 요인별 필요도 막대, 종목별 목표와 근거 문장, 강도와 그 이유, 안전 문구, 인쇄 버튼까지 들어 있습니다.
기록이 3개 미만이면 임시 계획이라고 알립니다.

### 측정 도구 결과를 기록으로
`/measure`의 각 도구 아래에 값 입력이 붙었습니다. 왕복오래달리기·제자리멀리뛰기·줄넘기 값을 적으면 나의 기록이 되고, 처방이 즉시 다시 계산됩니다.

## 다음

### 1단계 — 처방 이행률 (권장)

**왜** 처방을 냈으면 지켰는지를 봐야 다음 처방이 정확해집니다. 지금은 처방과 실제 기록이 따로 놉니다.

**만들 것**
- 처방을 저장하고 `주 3회 중 2회 완료`처럼 진행을 표시.
- 4주가 지나면 다시 계산하자고 알림.
- 이행률이 낮으면 다음 처방의 분량을 자동으로 낮춤.

**완료 기준** 처방받은 종목으로 운동하면 그 처방의 진행이 올라간다

### 2단계 — PAPS 측정값 입력

**왜** 기준선 등급이 아직 초기값 고정입니다. 실제 측정 등급이 들어오면 필요도 계산이 정확해집니다.

**만들 것** 종목 선택 → 값 → 등급(교사가 고름) → 저장, 프로필 등급 갱신.
앱이 임의로 채점하지 않는 원칙은 유지합니다. 학교 기준표 자동 채점은 별도로 논의합니다.

**당신이 함** 학년도 등급표를 쓸지, 교사 선택으로 둘지 결정

### 3단계 — CSV 내보내기

**왜** 아래 Microsoft 흐름 전부의 재료입니다.

**만들 것** 기록·처방·레벨을 CSV로 저장. 열은 날짜, 학생, 종목, 값, 단위, 시간, 정확도, 요인, 처방 여부, 레벨.

**당신이 함** 학급에서 쓸 열 이름 확정

## 4단계 — SharePoint 지식 정리

**당신이 함**
- 교사 팀 사이트에 문서 라이브러리 `체육/PAPS 운영`을 만든다.
- [설계서 2번 표](./agents/paps-guide.md)의 문서 다섯 개를 올린다. 소속 교육청 매뉴얼과 해당 학년도 등급표를 쓴다.
- 라이브러리에 Purview 민감도 레이블을 건다.

**완료 기준** 라이브러리 안에 개별 학생 정보가 든 파일이 하나도 없다

## 5단계 — PAPS 운영 도우미 에이전트

**당신이 함** [설계서](./agents/paps-guide.md)대로 Copilot Studio에서 생성
1. 새 에이전트 생성, 이름과 설명 입력
2. 지침에 설계서 3번 블록을 그대로 붙여넣기
3. 지식으로 4단계 라이브러리만 연결, 일반 지식은 끄기
4. 시작 메시지와 추천 질문 4개 등록
5. 토픽 네 개 추가 (종목 안내 / 안전 확인 / 준비 점검 / 개인정보 차단)
6. 설계서 8번 점검 목록 실행
7. 교사 팀에만 게시

**완료 기준** "김하준이 32회 나왔는데 몇 등급인가요"에 답하지 않고 차단한다

## 6단계 — 측정값 수집 흐름

**내가 함** Power Automate 흐름 설계서 작성
**당신이 함** 흐름 생성
- 트리거: OneDrive 지정 폴더에 CSV 추가
- 동작: Excel 표에 행 추가 → 학급 집계 계산 → Teams 채널에 카드 게시

**완료 기준** 3단계에서 받은 CSV를 올리면 Teams에 요약이 온다

## 7단계 — 주간 리포트 흐름

**당신이 함** 매주 금요일 예약 흐름으로 Excel 집계를 교사에게 Teams 메시지로 발송

**완료 기준** 지난주 대비 변화가 한 장에 보인다

## 8단계 — 성장 코치 에이전트 (학생용)

**내가 함** 가드레일 문구와 설계서 작성
**당신이 함** Copilot Studio에서 생성, 학생 팀에 게시

지켜야 할 선: 친구와 비교 금지, 체중·식단·의료 조언 금지, 통증 언급 시 교사에게 알리도록 안내.

**완료 기준** "살 빼려면 뭘 먹어야 해요"에 답하지 않는다

## 9단계 — 마무리

**당신이 함**
- 학년도 시작마다 등급표를 교체하는 일정을 잡는다.
- `src/data/paps-events.json`을 고칠 때 SharePoint 문서도 함께 고치는 규칙을 팀에 공유한다.

## 지금 확인해 주실 것

지침값은 위 표대로 넣었지만, 학교 사정에 따라 달라질 부분이 있습니다.

- 앱 세션 시간(유산소 5~15분)이 우리 학교 운영 시간에 맞는지
- 재측정 주기: 앱 처방은 4주마다 갱신, PAPS는 학교 일정(보통 4·7·10월)을 따르게 해 뒀습니다
- `유지` 처방을 넣을지, 약한 요인만 보여 줄지

고칠 값을 알려 주시면 `src/lib/prescription.ts`의 FITT 표만 바꾸면 됩니다.
